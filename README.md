# CodeAlpha Calculator

A responsive calculator built with **HTML, CSS and JavaScript** as part of my **CodeAlpha Frontend Development Internship (Task 2)**.

## Live Demo

https://YOUR-USERNAME.github.io/CodeAlpha_Calculator/

## Features

- Addition, subtraction, multiplication and division
- Decimal numbers, percentage (%), clear all (AC) and delete (DEL)
- Real-time display with the previous operation shown above the result
- Chained calculations (for example `5 + 3 + 2`)
- Divide-by-zero protection (shows "Error")
- Keyboard support: digits, `+ - * /`, `Enter`, `Backspace`, `Esc`
- Responsive design for mobile and desktop

## Technologies Used

- HTML5, CSS3 (Grid, transitions, media queries), JavaScript (ES6)

## How to Run

1. Clone the repo: `git clone https://github.com/YOUR-USERNAME/CodeAlpha_Calculator.git`
2. Open `index.html` in your browser (or use Live Server in VS Code).
